# Sicherheitslücken melden

Bitte Sicherheitslücken **nicht** als öffentliches Issue melden, sondern vertraulich:
Reiter **Security → Report a vulnerability** in diesem Repository.

Hilfreich sind: betroffene Seite oder Datei, Schritte zum Nachvollziehen und was ein Angreifer damit erreichen könnte.
Bitte keine echten Konten oder Daten anderer Nutzer verwenden und nichts veröffentlichen, bevor die Lücke behoben ist.

---

**Reporting a vulnerability:** please don't open a public issue. Use **Security → Report a vulnerability** in this repository instead.
